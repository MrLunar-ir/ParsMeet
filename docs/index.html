راهنمای ParsMeet نسخه 2.1.0

اولین و بهترین کتابخانه‌ی بات‌سازی برای CodeMeet با هوش مصنوعی داخلی

نصب

pip install ParsMeet

قابلیت‌های جدید نسخه 2.1.0

هوش مصنوعی چندگانه جدید OpenAI, Gemini, OpenRouter, KeylessAI
FSM (مکالمه چندمرحله‌ای) جدید ساخت فرم‌های پیچیده
Scheduler جدید زمان‌بندی خودکار
چندزبانه (i18n) جدید فارسی، انگلیسی و...
Webhook جدید برای سرورهای حرفه‌ای
سیستم Plugin جدید افزونه‌پذیر
CLI Scaffold جدید ساخت پروژه با یک دستور
Dashboard جدید آمار زنده‌ی ربات

شروع سریع

import ParsMeet
from ParsMeet import Filters

bot = ParsMeet.Bot(
    token="YOUR_TOKEN",
    ai_provider="keylessai",
    ai_memory=True
)

@bot.on_message(Filters.command & Filters.command_is("start"))
def start_handler(data):
    bot.send_message(data["chat_id"], "سلام! من آماده‌ام.")

@bot.on_askai()
def ai_handler(chat_id, text, username):
    return text

bot.run()

FSM - مکالمه چندمرحله‌ای

def ask_name(data, ctx):
    ctx["name"] = data["text"]
    return "ask_age"

def ask_age(data, ctx):
    ctx["age"] = data["text"]
    bot.send_message(data["chat_id"], f"سلام {ctx['name']}!")
    return None

bot.add_state("signup", "ask_name", ask_name, "ask_age")
bot.add_state("signup", "ask_age", ask_age)

@bot.on_message(Filters.command_is("signup"))
def signup(data):
    bot.start_conversation(str(data["user_id"]), "signup")

سیستم Plugin

فایل plugins/myplugin.py بساز:

from ParsMeet import Plugin

class MyPlugin(Plugin):
    name = "myplugin"
    version = "1.0.0"

    def setup(self, bot):
        @bot.on_message_all()
        def handler(data):
            bot.send_message(data["chat_id"], "Plugin working!")

bot.load_plugins("plugins")
